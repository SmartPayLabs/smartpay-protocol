# Roadmap

Phases are ordered by dependency, not by calendar. Dates are added only once a phase is genuinely scheduled.

## Phase 0: Foundation (in progress)

- [x] Brand assets and palette sampled from real files
- [x] Marketing site with live chain stats (block, gas, TVL)
- [x] Automated quality gates across five viewport widths
- [ ] Public repository and issue tracker
- [ ] Social channels announced

## Phase 1: Core contracts

- [ ] Payment request registry
- [ ] Router with firm quotes and expiry
- [ ] Settlement events and receipt schema
- [ ] Testnet deployment and public test flow
- [ ] First independent audit

## Phase 2: Wallet and checkout

- [ ] Hosted checkout link for merchants
- [ ] QR payment flow in a consumer wallet
- [ ] Recurring payments for subscriptions
- [ ] Receipt viewer with search and export

## Phase 3: Merchant coverage

- [ ] Merchant dashboard (balances, refunds, exports)
- [ ] SDK for web and mobile checkouts
- [ ] Category launches: streaming, rides, food, gaming, travel
- [ ] Refund and dispute flow backed by merchant bonds

## Phase 4: Open network

- [ ] Governance of fee bands and supported assets
- [ ] Third-party integrations programme
- [ ] Regional rollout plan, region by region
- [ ] Second audit and public bug bounty

Progress is tracked in the repository's issues. Items move forward only when they are shipped and verifiable.
